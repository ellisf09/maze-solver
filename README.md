![GitHub last commit](https://img.shields.io/github/last-commit/ellisf09/Maze-Solver)

<img src="https://skillicons.dev/icons?i=py">

A visual maze generator and pathfinding solver built in Python using `tkinter`.

## ✨ Features
- **Procedural Maze Generation:** Uses randomized depth-first search (recursive backtracking) to carve complex, solvable mazes on a grid.
- **Animated Pathfinding:** Visually animates the solving algorithm in real time, highlighting active exploration paths and backtracking dead ends.
- **Unit Tested:** Includes automated tests (`tests.py`) verifying grid initialization and cell wall breaking.

## 🚀 Usage
1. **Clone the repository:**
   ```bash
   git clone https://github.com/ellisf09/Maze-Solver
   cd Maze-Solver
   ```
2. **Run the visualiser:**
   ```bash
   python main.py
   ```
3. **Run tests:**
   ```bash
   python tests.py
   ```
